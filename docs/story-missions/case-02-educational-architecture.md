# Thinking Detectives Case 02 — Educational Architecture

## Status

**Approved on 2026-09-13.**

This document defines the story-neutral educational spine for Case 02. It does not choose the mystery, setting, cast, final problem wording, illustrations, or page design.

## Case-level learning goal

Case 02 should strengthen Amira's ability to:

1. find useful information;
2. infer the hidden unit in a partially labeled scale;
3. check a plausible idea against evidence;
4. preserve useful work while revising an unsuccessful path;
5. organize several constraints into a model and use it.

The approved educational spine is:

> **Find what matters → decode a hidden scale → check an idea → revise a path → build and use a model**

## Mission count

Use **five missions** for Case 02.

This is a Case 02 choice, not a permanent production standard.

Five missions are appropriate because:

- no available Case 01 observation indicates that five caused fatigue;
- five supports a complete confidence and difficulty progression;
- each mission can emphasize a distinct Primary Thinking Dimension;
- four capabilities that were supporting behaviors in Case 01 can receive greater emphasis;
- the final mission can test transfer of a previously practiced capability.

Continue observing whether five missions is the right chapter length.

## Relationship to Case 01

Case 01 used these Primary Thinking Dimensions:

1. Representation & Model Building
2. Working Backward
3. Decomposition
4. Elimination & Constraint Reasoning
5. Sequencing & Planning

Case 02 changes the mix rather than merely applying a new story skin.

It elevates previously supporting capabilities and adds one provisional dimension based on a specific learner observation:

- Useful-Fact & Anchor Finding
- Scale & Interval Reasoning
- Checking & Error Detection
- Strategy Revision
- Representation & Model Building as a transfer target

## Approved mission sequence

| Mission | Primary Thinking Dimension | Secondary Thinking Dimensions | Core reasoning experience |
| --- | --- | --- | --- |
| 1 | Useful-Fact & Anchor Finding | Representation & Model Building | Separate useful information from interesting but unnecessary details |
| 2 | Scale & Interval Reasoning | Useful-Fact & Anchor Finding; Decomposition | Infer the value of equal intervals from labeled reference points and use it to interpret an unlabeled position |
| 3 | Checking & Error Detection | Elimination & Constraint Reasoning; Relationship & Pattern Reasoning | Test plausible claims or plans, locate the first failure, and repair it |
| 4 | Strategy Revision | Checking & Error Detection; Decomposition | Preserve useful work from an unsuccessful approach and revise only what needs changing |
| 5 | Representation & Model Building | Sequencing & Planning; Elimination & Constraint Reasoning | Organize multiple constraints into a useful model and use it to reach a supported conclusion |

## Mission 1 — Find the useful foothold

### Educational purpose

Give the learner an approachable opening success while practicing the distinction between:

- information that is true;
- information that is interesting;
- information that is useful for the current question.

### Abstract task design

Present a small collection of facts containing:

- two or three necessary facts;
- one potentially useful anchor;
- one or two irrelevant but believable details.

Ask the learner to identify what she would use first and explain why.

### Productive-struggle target

The difficulty should come from deciding which information matters, not from computation.

### Valid paths

The learner might:

- circle the necessary facts;
- cross out irrelevant facts;
- group related information;
- draw a small representation;
- identify an anchor and work outward.

### Checking prompt

> Could you still solve the problem using only the facts you selected?

### Writing-space requirement

Provide:

- a place to mark or sort facts;
- a generous **Show Your Path** region;
- a short answer region afterward.

### Natural badge opportunity

**Clue Finder**

## Mission 2 — Decode the hidden scale

### Learner observation

This mission responds to an observed difficulty interpreting a bar-chart axis whose horizontal reference lines were labeled only at alternating intervals.

The example showed:

- a bottom line labeled 0;
- the next line unlabeled;
- the following line labeled 50;
- the next line unlabeled;
- the following line labeled 100.

The learner struggled to infer that the first unlabeled line represented 25.

The underlying challenge was not primarily calculating half of 50. It was recognizing that:

1. equally spaced lines represent equal numerical intervals;
2. 0 to 50 spans two equal intervals;
3. therefore each interval represents 25;
4. the intermediate unlabeled line must represent 25.

### Primary dimension

**Scale & Interval Reasoning** means:

> Infer the value of equal spaces or units from labeled reference points, then use the inferred unit to interpret an unlabeled position.

This capability transfers to:

- graphs and chart axes;
- number lines;
- timelines;
- rulers;
- thermometers;
- measuring containers;
- maps and distance scales;
- gauges;
- elevation charts.

It is a provisional standalone dimension for Case 02 and should be evaluated after learner use before becoming a permanent taxonomy standard.

### Abstract task design

Use a precise vertical or horizontal scale containing:

- equally spaced reference lines or tick marks;
- 0 at the starting line;
- 50 two intervals away;
- 100 another two intervals away;
- unlabeled marks between them;
- an object, bar, point, or indicator aligned with an unlabeled mark.

The learner should first determine the value of one interval and then interpret the indicated value.

The final story plan may reskin the representation as a gauge, height marker, distance scale, storage-level indicator, or another story-relevant device. The educational relationship must remain unchanged.

### Reasoning sequence

#### Part A — Determine the unit

> What amount does one space between neighboring lines represent?

#### Part B — Interpret the representation

> What value does the indicated line, bar, point, or object represent?

### Productive-struggle target

The difficulty should be recognizing the hidden unit from the structure of the scale.

Keep the arithmetic simple:

- difference between labeled anchors: 50;
- number of equal intervals: 2;
- value of each interval: 25.

Avoid awkward values or complicated division in this first targeted mission.

### Important distinction

The learner must reason about **spaces or intervals**, not merely count visible lines.

From the line labeled 0 to the line labeled 50, there are three visible lines but only two equal spaces or jumps.

Do not explain this distinction in the initial task. Noticing the intervals is part of the intended reasoning. Reveal it progressively through hints if needed.

### Valid paths

The learner might:

- count equal jumps from 0 to 50;
- split 50 into two equal parts;
- label the scale 0, 25, 50, 75, 100;
- work backward from 100;
- notice that the unlabeled mark is halfway between 0 and 50;
- label every mark and verify equal increments.

### Hint ladder

1. **Attention hint:** “Look only at the lines marked 0 and 50. How many equal jumps are between them?”
2. **Structure hint:** “The value changes by 50 across two equal spaces.”
3. **Directional hint:** “If two equal spaces together represent 50, what does one space represent?”
4. **Strong hint:** “Split 50 into two equal parts, then label the lines 0, 25, and 50. Continue the same pattern toward 100.”

### Checking prompts

> If every interval is worth the same amount, do your labels increase equally each time?

> Starting at 50, can you make two equal jumps and land exactly on 100?

### Writing and interaction requirements

Allow the learner to annotate the scale or label the missing marks directly.

Keep the response order:

1. **Show Your Path**
2. **One interval represents:** ___
3. **The indicated value is:** ___

The functional graphic must be large, precise, and free of decorative clutter. Equal intervals must be geometrically equal.

### Short transfer check

After the main task, optionally include one brief transfer check using a different orientation or context:

- vertical scale becomes horizontal;
- grid lines become tick marks;
- a bar becomes an arrow or object;
- labels start at a value other than zero.

Keep the numbers simple. The purpose is to determine whether the learner understands interval structure rather than memorizing the sequence 0, 25, 50, 75, 100.

The transfer check must remain short enough that it does not become a second mission.

### Natural badge opportunities

**Clue Finder** and **Check-It**

## Mission 3 — Find where the idea breaks

### Educational purpose

Make checking the central job rather than an afterthought.

### Abstract task design

Present two or three plausible claims, routes, arrangements, or proposed solutions. At least one should contain a meaningful inconsistency.

Ask the learner to:

1. test each proposal;
2. identify the first point where one fails;
3. explain or repair the error.

### Productive-struggle target

The incorrect proposal should look plausible. Its error must violate a visible fact or constraint, not depend on a trick, hidden assumption, or ambiguous wording.

### Valid paths

The learner might:

- check every constraint systematically;
- test the most restrictive fact first;
- compare proposals side by side;
- eliminate possibilities;
- reconstruct the faulty step.

### Checking prompt

> After your repair, does every fact work—not just the fact that was broken before?

### Writing-space requirement

Include:

- **Where does it first stop working?**
- **How would you repair it?**
- **Show Your Path**
- **Your Answer**

### Natural badge opportunity

**Check-It**

## Mission 4 — Keep what works and revise the rest

### Educational purpose

Directly practice strategy revision and make an unsuccessful attempt feel useful.

### Abstract task design

Provide—or allow the learner to create—an approach that gets partway toward the goal but eventually stalls or contradicts a fact.

Ask:

- What part still works?
- Where did the path stop helping?
- What could change without restarting everything?

### Productive-struggle target

The learner should resist two unhelpful extremes:

- continuing a path after evidence shows it is not working;
- discarding all previous work when part of it remains useful.

### Valid paths

The learner might:

- backtrack to the last valid step;
- replace one assumption;
- divide the task differently;
- switch representations;
- test a second route.

### Checking prompt

> Which part of your original path did you keep, and why is it still valid?

### Writing-space requirement

Provide flexible areas for:

- **What still works?**
- **What will you change?**
- **Your new path**
- **Your Answer**

These prompts should support revision without prescribing the method.

### Natural badge opportunities

**Try Again** and possibly **Brave Try**

## Mission 5 — Build a model and use it

### Educational purpose

Create a capstone that integrates several pieces of information without requiring heavy computation.

This also tests whether the learner can transfer Representation & Model Building from Case 01 into a substantially different situation.

### Abstract task design

Present several locations, events, objects, steps, or constraints. The learner must organize them into a model before deciding what can happen, where something belongs, or which plan works.

Do not supply the representation too completely. Allow meaningful freedom to use:

- a diagram;
- a table;
- an organized list;
- a timeline;
- a route model;
- another clear representation.

### Productive-struggle target

The difficulty should come from choosing how to organize the information and coordinating several constraints.

Keep computation light.

### Valid paths

At least two different representations should support a valid solution.

### Checking prompt

> Can you use your model to verify every condition one at a time?

### Writing-space requirement

Give this mission the largest free working area in the case. Avoid dividing the page into so many boxes that the learner cannot invent her own representation.

### Natural badge opportunities

**Path Builder** and **Check-It**

## Difficulty progression

| Mission | Intended experience |
| --- | --- |
| 1 | Accessible entry: find a foothold independently |
| 2 | Focused representation challenge: infer and apply a hidden unit |
| 3 | Moderate challenge: detect and repair a plausible error |
| 4 | Highest emotional challenge: revise without treating the first attempt as failure |
| 5 | Integrative capstone: organize multiple constraints into a model |

Numerical work should remain light throughout. Difficulty should increase through reasoning coordination, not larger numbers or more complicated arithmetic.

Mission 4 may be more emotionally difficult than Mission 5 even if Mission 5 is cognitively broader. This is acceptable and intentional.

## Confidence progression

The missions should create this learner experience:

1. **I can find somewhere to start.**
2. **I can decode what an unlabeled interval means.**
3. **I can find what went wrong.**
4. **I can keep useful work and change my plan.**
5. **I can organize a complicated situation and solve it.**

## Case-wide hint architecture

Use the established progression:

1. **Attention hint:** Direct attention toward something useful.
2. **Structure hint:** Suggest a way to organize or compare information.
3. **Directional hint:** Clarify the next reasoning move.
4. **Strong hint:** Restore movement without simply supplying the answer.

Missions 1–3 may need only three hints. Missions 4–5 should allow four because revision and model building create more possible sticking points.

Do not name an arithmetic operation prematurely.

## Case-wide checking strategy

Checking should recur across the case rather than appear only in Mission 3:

- Does my selected information answer the actual question?
- Does the unit I inferred produce equal changes across the whole scale?
- Where does this proposal first violate a fact?
- Which parts of my unsuccessful path remain valid?
- Does my final model satisfy every constraint?

## Badge plan

Retain the existing badge set:

- Clue Finder
- Path Builder
- Brave Try
- Check-It
- Try Again

Do not add new badges for Case 02.

Case 02 should create especially natural opportunities for **Check-It** and **Try Again**. Badges remain optional recognition, not automatic rewards or a score.

## Observation targets

Observe whether Amira:

- finds relevant facts without immediately asking for a method;
- explains why a fact is useful;
- uses labeled values as anchors;
- counts intervals rather than visible lines;
- infers a constant value per interval;
- labels missing marks independently;
- checks an inferred unit against another labeled value;
- transfers the interval reasoning to a slightly different representation;
- tests a plausible answer rather than accepting it;
- identifies where an approach stopped working;
- preserves useful partial work;
- revises without restarting unnecessarily;
- chooses or invents a representation;
- uses hints to resume thinking rather than wait for an answer;
- experiences revision as progress instead of failure;
- has sufficient writing and drawing space;
- maintains interest across five missions.

For Mission 2, distinguish whether difficulty comes primarily from:

- interpreting equal intervals;
- selecting useful anchors;
- decomposing the numerical difference;
- reading a visual representation;
- coordinating those steps.

This architecture does not decide:

- story premise or setting;
- supporting cast;
- story clues or suspects;
- final numerical values outside the approved Mission 2 target;
- surface theme of any task;
- final page count;
- grayscale versus limited color;
- illustrations or final functional-graphic designs.
