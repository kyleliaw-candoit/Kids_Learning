# Thinking Mission Classification Rule

Each future Thinking Mission should be tagged with:

- **one Primary Thinking Dimension** — the main reasoning capability the mission is intentionally designed to exercise;
- **up to two Secondary Thinking Dimensions** — other meaningful reasoning capabilities that the learner is likely to practice while solving it.

The Primary dimension should drive problem design. Secondary dimensions should describe real supporting cognitive work, not be added merely because they are loosely present.

This tagging rule is intended to make the mission library auditable: we should be able to see which thinking capabilities are well represented, which are underrepresented, and deliberately create more missions in a chosen dimension.
